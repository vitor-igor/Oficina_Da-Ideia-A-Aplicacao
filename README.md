# Oficina - Da Ideia à Aplicação Web: Desenvolvendo Soluções para Diferentes Contextos

Nesta oficina, os participantes participarão de uma experiência prática de desenvolvimento de uma aplicação web completa, na qual cada um poderá escolher entre diferentes propostas de sistema previamente definidas, como uma plataforma de valorização e divulgação de mulheres na ciência, um catálogo de projetos acadêmicos, um sistema de eventos ou uma plataforma de divulgação de laboratórios e grupos de pesquisa. A partir do contexto escolhido, os participantes serão conduzidos pelas principais etapas de construção da aplicação, passando pela compreensão dos requisitos e pela modelagem dos dados até a implementação de uma API e sua integração com uma interface web.

Apesar de trabalharem com propostas diferentes, os participantes desenvolverão sistemas com estruturas e níveis de complexidade semelhantes. Dessa forma, a oficina permitirá observar, na prática, como conhecimentos de Engenharia de Software, Banco de Dados e Desenvolvimento Web podem ser combinados para construir soluções destinadas a diferentes problemas, ao mesmo tempo em que evidencia elementos e decisões que podem ser reaproveitados entre aplicações.

Como referência, serão utilizadas experiências do desenvolvimento do BVApp, plataforma desenvolvida no contexto da disciplina Projeto Integrador I do Bacharelado em Engenharia de Software e do projeto de extensão “Tecnologias e Sustentabilidade: Desenvolvimento de Aplicativo e Soluções Digitais para uma Cooperativa de Energia Solar”. A partir desse paralelo com um projeto real, a oficina busca aproximar os conhecimentos trabalhados no curso de sua aplicação integrada no desenvolvimento de software.
Ao final, os participantes terão construído uma aplicação funcional dentro do contexto escolhido e poderão comparar os diferentes resultados, identificando como uma estrutura semelhante pode servir de base para sistemas voltados a necessidades distintas.
